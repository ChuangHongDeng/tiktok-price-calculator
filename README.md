# TikTok 售价计算器

一个无需安装、可离线使用的跨境电商定价工具。

## 使用

双击打开 `index.html`。输入每件商品的固定成本、跨境物流、平台及经营费率、目标利润率、活动折扣和销售数量，工具会实时给出单件折后售价、商品原价，以及按数量汇总的总成交额与总利润。

物流价表可在 `shipping.html` 中维护。模板按国家分工作表，每张表保留“重量（克）”和“全境(当地货币)”两列。导入前可为每个市场设置最大计费重、最大体积和体积重换算系数，超过重量上限的价格行会被忽略。

`guide.html` 提供面向新手的售价公式、数据来源、输入/计算标记和完整示例。

`solutions.html` 介绍工具价值、真实使用场景，以及精度、封顶费用和数据可信度等设计方案。

售价计算页的输入会自动保存在当前浏览器中；物流页会保存计费范围和导入价表，查询市场与查询重量仅用于当前查看。

## 计算口径

```text
未触发项目费封顶：
折后售价 = (固定成本 + 跨境物流 + 马来尾程 SST + 每单固定费) / (1 - 综合费率 - 项目费率 - 目标利润率)

触发项目费封顶：
折后售价 = (固定成本 + 跨境物流 + 马来尾程 SST + 每单固定费 + 项目费封顶额) / (1 - 综合费率 - 目标利润率)

商品原价 = 折后售价 / (1 - 活动折扣)
```

- 固定成本统一以人民币输入，再按手动汇率换算为销售币种。
- 综合费率是平台佣金、交易/渠道手续费、达人佣金、广告占比、税费和退货损耗预留之和。
- 项目服务费按 `成交价 × 项目费率` 与封顶额中的较低值计算，封顶额为 0 时不封顶。
- 参考物流价卡会将商品实重向上取整到 10g，再查算对应市场的跨境物流费。
- 平台对马来跨境商家尾程运费征收服务税（SST）；计算页将该税率作为可编辑项，默认 6%，填写 0 即不征收。
- Excel 导入按市场分别替换价表，也兼容带市场代码、重量上限和物流费列的明细格式。
- 体积可通过长、宽、高计算，也可直接输入；体积重（kg）= 体积（cm³）÷ 维护页设置的换算系数。
- 物流计费重取商品实重和体积重中的较大值，再向上取整到价表重量档。
- 目标利润率以折后成交价为基数。
- 销售数量按单件口径汇总总额；单件折后售价与商品原价不受数量影响，总成交额、总成本与总利润为单件金额乘以数量。
- 中间计算保留完整精度；建议售价和商品原价按销售币种的最小单位向上取整，确保取整后仍达到目标利润率。人民币换算及利润展示采用四舍五入（ROUND_HALF_UP）保留两位小数。

## 官方参考表口径

市场预设和物流估算参考用户提供的 TikTok Shop 东南亚跨境商品定价表：

- 物流价卡更新日期：2026-01-08。
- 费率参考表更新日期：2026-01-28。
- 平台佣金会因市场、类目、Mall/非 Mall、活动资格等变化，预设值只用于快速起算，实际定价前应按商家后台更新。
- 原表越南示例存在跨行异常引用，且其含税展示价口径与其他市场不同；本工具没有复制该异常引用，税费统一作为折后成交价的可编辑比例成本处理。
